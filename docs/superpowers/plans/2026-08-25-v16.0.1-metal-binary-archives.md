# v16.0.1 Metal Binary Archives Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v16.0.1 with native archive-backed `workerHmac_seq` and `workerBip38Grouped` pipeline specializations for all 11 Apple Silicon GPU architectures.

**Architecture:** A deterministic Python build helper is the single source of truth for the three specialization profiles, their function constants, runtime pipeline keys, specialized names, and expected GPU slices. It generates both the Metal translator configuration and a C++ header, builds one thin archive per GPU architecture, and combines them. `MetalRuntime` loads the embedded archive and requires archive hits for the exact generated profiles before falling back to the existing AIR 2.6 library for all other pipelines.

**Tech Stack:** Python 3 standard library, GNU Make, Apple Metal tools (`metal`, `metallib`, `metal-tt`, `metal-lipo`), Objective-C++17, Metal binary archives, POSIX temporary files, shell release packaging.

**Spec:** `docs/superpowers/specs/2026-08-25-v16.0.1-metal-binary-archives-design.md`

## Global Constraints

- Keep the host executable arm64 with minimum macOS 15.0.
- Keep the fallback metallib at AIR 2.6/platform 14.
- Compile native archive entries for the Tahoe 26 Metal runtime reported in issue #1; retain AIR fallback on older or changed runtimes.
- Embed exactly `applegpu_g13g`, `applegpu_g13s`, `applegpu_g13d`, `applegpu_g14g`, `applegpu_g14s`, `applegpu_g14d`, `applegpu_g15g`, `applegpu_g15s`, `applegpu_g15d`, `applegpu_g16g`, and `applegpu_g16s`.
- Archive only the compressed BIP32 `workerHmac_seq` profile and BIP38 profiles 28 and 30.
- Keep `windowBits=16`, `windows=17`, ADA mask 1023, DOT mask 3, and BIP32 derivation mask 1 for issue-compatible specializations.
- Preserve AIR fallback for archive misses unless `METAL_REQUIRE_BINARY_ARCHIVE=1` is set for verification.
- Do not move tag `v16` or replace its assets; publish a new `v16.0.1` tag and release.
- Do not modify, stash, clean, or reset the primary dirty checkout.
